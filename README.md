# Darren Tamayo Portfolio

Personal portfolio website for Darren Tamayo, built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive single-page layout
- Light and dark themes
- GitHub-backed project showcase
- Project filtering and details modal
- Downloadable resume
- Contact form ready for Formspree configuration

## Run locally

Open `index.html` in a browser, or serve the repository with any static-file server.

## Publish

The site is static and can be deployed with GitHub Pages, Netlify, or Vercel.
